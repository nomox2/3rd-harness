# 하네스 역할 정의

## 에이전트별 권한

| 에이전트 | 담당 스테이지 | 쓰기 가능 | 읽기만 |
|---|---|---|---|
| uibowl 에이전트 | S1 | output/{화면이름}/ | - |
| 디자인 에이전트 | S2 | output/{화면이름}/ | - |
| 검증 에이전트 | S3 | - | output/{화면이름}/, rules/ |
| 판정자 에이전트 | 게이트 전 구간 | - | rules/design-rules.md |

## 판정자 규칙
- 파일 수정 불가
- rules/design-rules.md 기준으로만 통과/실패 판단
- 판단 결과를 오케스트레이터에게 반환

## 트리거
- 자연어로 시작
- 예: "판매 신청 화면 디자인 시작해줘" → 하네스 자동 실행
