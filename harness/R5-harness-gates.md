# 하네스 게이트 정의

## 스테이지별 통과 조건

| 스테이지 | 통과 조건 |
|---|---|
| S1 | s1-references.md 존재 + 항목 3개 이상 |
| S2 | s2-spec.md, s2-keyscreen.md 파일 존재 |
| S3 | s3-review.md 위반 사항 0개 |

## 사람 승인 지점
- 5단계 시안 확정: 내부 관계자 승인 1명 이상 → S3 계속 진행
- 반려 시: 3단계(화면 설계)로 복귀
## 어기면 안 되는 것 (story-service.md 연동)
S3 진입 전 자동 확인:
- [ ] 설계 문서에 "본인이 선택" 플로우가 명시됐는가
- [ ] 설계 문서에 "운영자 검수" 단계가 명시됐는가
→ 둘 중 하나라도 없으면 S3 진입 차단
