# 하네스 파이프라인 정의

## 단계 묶음

| 스테이지 | 포함 단계 | 담당 에이전트 | 입력 | 출력 | 다음으로 |
|---|---|---|---|---|---|
| S1 | 1. 레퍼런스 수집 | uibowl 에이전트 | 화면 이름 | 경쟁사 레퍼런스 수집본 | AI 자동 → S2 |
| S2 | 2. 분석<br>3. 화면 설계<br>4. 키스크린 | 디자인 에이전트 | S1 출력 | 분석 결과, 설계 문서, 키스크린 | AI 자동 → S3 |
| S3 | 5. 시안 확정<br>6. 토큰·컴포넌트·화면 제작<br>7. 가이드 검토 | 검증 에이전트 + 사람 게이트 | S2 출력 | 확정 시안, 디자인 산출물, 검토 결과 | 위반 0개 → 완료 |

## 되돌아가기
- 5단계 내부 관계자 반려 → 3단계(화면 설계)로 복귀
