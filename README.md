# 허들링 디자인 하네스

AI 실무 콘텐츠 플랫폼 **허들링**의 화면 디자인 작업을 자동화하는 하네스입니다.
디자이너가 화면 이름을 입력하면 레퍼런스 수집 → 화면 설계 → Figma 제작 → 가이드 검증까지 자동으로 실행됩니다.

---

## 구조

```
3rd-harness/
├── CLAUDE.md              # 하네스 실행 설명서 (오케스트레이터가 읽는 파일)
├── docs/
│   ├── prd.md             # 서비스 PRD
│   ├── design.md          # 디자인 가이드라인
│   ├── story-service.md   # 유저스토리 + 금지 규칙
│   └── story-work.md      # 작업 흐름 정의
├── harness/               # R2~R8 하네스 설계 문서
├── rules/
│   └── design-rules.md    # 가이드 위반 판정 기준 (SSOT)
└── output/                # 화면별 산출물 (레퍼런스, 설계서, 키스크린)
```

---

## 파이프라인

| 스테이지 | 내용 | 전환 |
|---|---|---|
| S1 | 경쟁사 레퍼런스 수집 (uibowl) | 자동 |
| S2 | 분석 → 화면 설계 → Figma 키스크린 제작 | 자동 |
| S3 | 시안 확정 → 가이드 위반 검토 | 위반 0개 → 완료 |

---

## 시작하는 법

```
{화면 이름} 디자인 시작해줘
```

예: `판매 신청 화면 디자인 시작해줘`

## 서비스 소개

**허들링**은 AI 실무 콘텐츠 플랫폼입니다.

- 무료 학습자: 공개 AI 실무 콘텐츠 탐색
- 유료 멤버: 강의자료·프롬프트·스킬 파일·미션 접근
- 판매 승인 회원: 자신의 자산을 마켓에 판매 신청
